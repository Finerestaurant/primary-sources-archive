# 조사 — 어디에 무엇이 있는지 찾아본 기록

문서철이 아니다. **사료를 찾아다닌 흔적**이다. 무엇이 공개돼 있고 무엇이 없는지,
어디서 받을 수 있고 어디가 막혔는지를 실측해 남긴다.

같은 곳을 두 번 뒤지지 않으려고 둔다.

---

## 무엇을 찾고 있었나

김구 피살(1949년 6월 26일)에 관한 미국 문서를 찾다가, 계통 전체로 넓혔다.
결론부터 적는다.

> **미국 정부가 공개한 문서 가운데 김구 피살을 다룬 것은 무초의 전보 한 건뿐이다.**

| 계통 | 1949년 6월 김구 | 확인 방법 |
|---|---|---|
| 국무부 (FRUS) | **1건** (`49-d265`) | 세 권 XML 전수 검색 |
| CIA (CREST) | **0건** | 23,664건 전수 검색 |
| 육군 방첩 (RG 319 IRR) | 온라인 공개본 없음 | NARA 카탈로그·IWG 목록 |
| NDL 점령기 자료 | **0건** | 091 File 3 을 267면 OCR |

CREST 1949년 조선 관련 문서는 328건 확보했는데 김구는 0건이다. 1948년에 6건,
1951년에 2건 나오므로 자료가 없어서가 아니다.

## 알아 둘 것

**CREST 날짜는 1989년 이후가 믿을 수 없다.** 아카이브닷오르그 메타데이터의
`date` 가 문서 작성일이 아니라 **비밀해제 처리일**인 경우가 섞여 있다. 1998년
221건을 열어 보니 라오스 항공작전(1955–74), 이라크 미사일 회고록(1990) 따위였다.
1998년 7월에만 82건이 몰려 있는 것이 배치 처리의 흔적이다.

**1940~50년대도 안심할 수 없다.** 표본으로 맞춰 볼 때는 맞았는데, 실제로 문서철을
지으려고 21건을 전수 대조하니 한 건이 어긋났다. `cia-rdp79-01090a000400060003-9`
는 메타데이터 날짜가 `1946-05-10` 인데 머리글이
`INTELLIGENCE HIGHLIGHTS - WEEK OF 4 MAY - 10 MAY 1948` 이다. **월과 일은 맞고
연도만 두 해 어긋났다.** 그래서 날짜만 보아서는 걸러지지 않는다.

    본문에서 연도를 뽑아 메타데이터와 맞춰 본다
    → 메타 연도가 본문에 한 번도 안 나오면 열어 본다

**아카이브닷오르그 식별자는 대문자다.** `crest_ids.json` 에는 소문자로 들어
있는데, 그대로 주소를 만들면 **전부 404 다.**

    https://archive.org/details/cia-rdp82-00457r000100370010-3   404
    https://archive.org/details/CIA-RDP82-00457R000100370010-3   있다

본문(`_djvu.txt`)은 소문자로도 받아졌기 때문에 여태 드러나지 않았다.
문서철에 걸어 둔 원본 링크 291건이 죽어 있었다.

**스캔이 있고 가볍다.** 항목마다 `Image Container PDF` 가 있는데 한 면에
40~110KB다. 한두 면짜리 첩보보고가 대부분이라 310건을 다 받아도 30MB 안팎이다.
`__ia_thumb.jpg`(10KB)도 항목마다 있어 썸네일로 쓸 수 있다.
**NARA 의 28MB 무압축 TIFF 와 혼동하지 마라. 전혀 다르다.**

**메타데이터 API 가 자주 빈 `{}` 를 돌려준다.** HTTP 200 인데 내용이 없다.
연달아 부르면 그렇게 되고, 세 번 다시 불러도 마찬가지다. **초당 한 건 이하로,
빈 응답이 오면 한참 쉬었다 다시 붙어야 한다.** 국편 DB 에서 겪은 것과 같은 일이다.

**같은 문서가 두 번 들어 있는 일이 있다.** CREST 는 부서마다 남은 사본을 따로
디지털화해서, 한 간행물이 서로 다른 문서번호로 두 벌 올라와 있다. 1948년치에서
두 쌍이 나왔다 — 「KOREA: EVALUATION OF MAPS」(`M-7`)와 「THE CURRENT SITUATION
IN KOREA」(`ORE 15-48`)다. **날짜와 제목이 달라 보여도 같은 것일 수 있다.**
뒤의 쌍은 메타데이터 날짜가 1948-02-04 와 1948-03-18 로 한 달 반 벌어져 있었다.

    # 여덟 낱말 조각이 얼마나 겹치는지 본다
    def shingles(t, k=8):
        w = re.findall(r'[a-z]+', t.lower())
        return {' '.join(w[i:i+k]) for i in range(len(w) - k)}
    len(A & B) / len(A)      # 0.9 를 넘으면 같은 문서다

사본마다 읽히는 데가 다르다. 한쪽에만 표지 발행일이 남고 다른 쪽에만 배포처
목록이 남는 식이다. **더 온전한 쪽을 싣고 다른 쪽의 문서번호를 주에 적어 둔다.**

**판단서(ORE)는 표지에 날짜가 찍혀 있으니 그것을 보면 된다.** 1947년치 68건을
훑어 보니 어긋난 것이 둘 다 판단서였다. `ORE 5/1` 은 메타 1월 5일에 표지 1월
3일, `ORE 62` 는 메타 10월 2일에 표지 **11월 18일**이다. 뒤의 것은 한 달 반
차이라 그냥 두면 유엔 총회 표결(11월 5일)보다 앞선 문서가 되어 버린다.

이때 **정보보고의 `DIST.` 날짜는 어긋난 것이 아니다.** 중앙정보단 제식
`INTELLIGENCE REPORT` 는 정보를 얻은 시점과 배포한 시점이 다르다. 1946년 11월
일을 적은 보고가 1947년 2월에 배포된 것이 여럿 있고, 메타데이터 날짜는 앞의 것을
가리킨다.

**국편 DB(`db.history.go.kr`)가 우리 IP를 막았다.** 20갈래로 4,650건을 요청한
탓이다. `www.history.go.kr` 과 `archive.history.go.kr` 은 열린다. 다시 붙일 때는
**초당 한 건 이하**로.

**NARA 온라인 공개본은 받을 것이 못 된다.** 조선 관련만 5,444건인데 개체가
340만 장, **57TB** 다. 한 장 28MB 무압축 TIFF 이고 축소본 엔드포인트가 없다.
게다가 `korea` 검색이 부정확하다. RG 319 의 「부관감 1949.6–1950.1」 문서철을
60장 표본으로 받아 OCR 해 보니 **조선과 무관한 본토 행정 지시철**이었다.

**정보원 평가등급(A-1 … F-6)** 은 전 시기 조선 관련에서 **A가 하나뿐**이다
(1945년 JANIS 75 지형 연구). 1948–54년에는 A가 없고 C와 F 뿐이다.
1980년대 문서의 `(A-1)` 은 정보원 등급이 아니라 **배포처 사무실 코드**다.
