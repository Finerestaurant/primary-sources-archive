# BARCH_20Juli1944

1944년 7월 20일 히틀러 암살 미수 직후, 나치 정권이 **자기 내부의 반응을 스스로 기록한**
문서철. 독일연방문서보관소(Bundesarchiv) `NS 6`(당총재비서실, Partei-Kanzlei der NSDAP)
소장 자료를 invenio에서 직접 받았다.

이 저장소가 지금까지 다룬 자료(FRUS, JACAR, CREST 등)는 전부 **미국 또는 일본** 쪽
기록이었다. 이번이 독일 측 원본을 다루는 첫 시도다(2026.8.13 착수).

## 왜 이 사건인가

이 저장소의 다른 문서철들과 마찬가지로 "굵직한 사건 자체"가 아니라 **그 경위를
내부에서 어떻게 판단했는지**를 담은 기록을 우선했다. 7월 20일은:

- 정권이 하루하루 자기 국민의 반응을 SD(친위대안전부) 여론보고로 측정한 기록이
  고스란히 남아 있고 (`NS 6/2`),
- 연좌제(Sippenhaft)가 실제로 작동하는 순간 — 암살자 본인이 아니라 **혐의도
  불명확한 숙부가 조사 완료 전에 먼저 체포되는** 과정 — 이 지방 당 조직의
  보고서로 남아 있고 (`NS 6/3`),
- 쿠데타의 "총통 사망" 텔레타이프 전문이 통신장교 한 명의 의심으로 무산되는
  과정이 분 단위로 재구성돼 있고 (`NS 6/4`),
- 한 달 뒤 수사가 괴르델러·로이슈너 검거로 이어지는 종합보고가 있다 (`NS 6/9`).

## 현재 상태 — 사이트에 걸려 있음, 대부분 부분 번역

`site.json`의 `attentat-20juli` 문서철로 공개돼 있다(주제 threads에는 없음 —
문서철에만 반영하기로 함). JACAR와 같은 파이프라인:

```
BARCH_20Juli1944/
  pages/, thumbs/     지면 스캔·썸네일 (q75 JPEG)
  tr/*.json           번역 (JACAR 스키마, ja→de만 교체)
  pipeline/
    문서목록.json      사건·문서 목록
    make_docs.py       tr/*.json → reading/docs.json
    초역_상세/          압축 전 전문 번역 원고(문장 단위 대조용)
  reading/
    collection.json    열람기 설정
    docs.json           make_docs.py 산출물(커밋 안 함 — 재생성)
```

## 원본 접근 방법 (재현용)

invenio의 "Digitalisat anzeigen"은 PrimeFaces AJAX라 팝업이 항상 크롬 확장에
막힌다 — 아래 방식으로 우회한다.

1. invenio 검색 결과 페이지에서 항목의 "Digitalisat anzeigen" 링크 onclick 안의
   `id`(UUID, 예: `name:"id",value:"..."`)를 찾는다.
2. **그 링크를 실제로 한 번 클릭**해 서버 세션에 그 id를 "열람 승인"시킨다
   (팝업 자체는 크롬 확장이 못 건드리는 별도 창이라 무시해도 된다 — 클릭이
   AJAX 요청을 보내는 것 자체가 목적).
3. 곧바로 `https://invenio.bundesarchiv.de/invenio/digitalisat?id={id}` 로
   **직접 navigate**한다 — 이번엔 팝업이 아니라 일반 페이지라 자동화 가능.
   (이 단계를 2번 없이 바로 하면 "Fehlermeldung"·429 오류가 난다 — 반드시
   먼저 목록에서 클릭해 세션에 id를 승인시켜야 한다.)
4. 우측 상단 **Download → "Gesamte AE (ZIP)"**가 기본 선택된 채로
   **"Download starten"** 클릭.

**주의**: 서버가 짧은 시간에 여러 요청을 보내면 429(Too Many Requests)로 막는다
(실제로 한 번 걸렸다). 항목 사이에 충분한 간격을 둘 것 — 공공기관 서버이니
예의를 지킨다.

## 저작권

Bundesarchiv는 FRUS(미국 정부 저작물)나 JACAR와 달리 **재사용에 대한 포괄적
허가를 주지 않는다** — "재사용자가 스스로 저작권법을 확인하라"는 입장이다.
다만 이 문서들은 1944년 작성된 **관공서의 익명 직무 저작물**(작성자 개인 서명
없음)이라, 독일 저작권법상 익명저작물 보호기간(발행 후 70년)이 이미 지났을
가능성이 높다 — 다만 이건 확정된 결론이 아니라 추정이며, 재확인이 필요하다.
