# BARCH_20Juli1944

1944년 7월 20일 히틀러 암살 미수 직후, 나치 정권이 **자기 내부의 반응을 스스로 기록한**
문서철. 독일연방문서보관소(Bundesarchiv) `NS 6`(당총재비서실, Partei-Kanzlei der NSDAP)
소장 자료를 invenio에서 직접 받았다.

이 저장소가 지금까지 다룬 자료(FRUS, JACAR, CREST 등)는 전부 **미국 또는 일본** 쪽
기록이었다. 이번이 독일 측 원본을 다루는 첫 시도다.

## 왜 이 사건인가

이 저장소의 다른 문서철들과 마찬가지로 "굵직한 사건 자체"가 아니라 **그 경위를
내부에서 어떻게 판단했는지**를 담은 기록을 우선했다. 7월 20일은:

- 정권이 하루하루 자기 국민의 반응을 SD(친위대안전부) 여론보고로 측정한 기록이
  고스란히 남아 있고 (`NS 6/2`),
- 연좌제(Sippenhaft)가 실제로 작동하는 순간 — 암살자 본인이 아니라 **혐의도
  불명확한 숙부가 조사 완료 전에 먼저 체포되는** 과정 — 이 지방 당 조직의
  보고서로 남아 있다 (`NS 6/3`).

## 현재 상태 — 초벌 번역, 파이프라인 미구축

**아직 사이트에 걸리지 않았다.** JACAR_독단전행처럼 `make_docs.py` /
`collection.json` / `build.py` 연동 전 단계다. 지금 있는 것은:

```
BARCH_20Juli1944/
  pages/     지면 스캔 (JPEG, q75로 축소 — 열람기/shrink_pages.py 적용됨)
  tr/        번역 JSON (스키마는 JACAR tr/*.json 과 거의 같음, ja→de)
  pipeline/  (비어 있음 — 문서목록.json, make_docs.py 등은 아직 없음)
```

`tr/*.json` 필드는 JACAR 방식을 그대로 따르되 원문 언어 필드만 `ja` 대신 `de`를
쓴다: `ref, event, archive, pages, date, date_src, doc_type, author, title_de,
title_ko, subject_ko, key_points_ko, de, ko, redactions, people, confidence, notes`.

## 받은 문서

| 서명 | 쪽수 | 내용 | 번역 상태 |
|---|---|---|---|
| NS 6/2 | 44 | SD 여론보고 4건(7.21–7.24) | **완료** (`tr/NS6-2.json`) |
| NS 6/3 | 56 | 슈타우펜베르크 가문 조사·계보 | **부분** — 그라이펜슈타인 성 연좌 조사 부분만 (`tr/NS6-3.json`). 계보학 발췌·후속 수사 경과는 미착수 |

`tr/*.json`은 보고서별 원문·번역을 절 단위로 발췌·압축한 것이다. 문장 하나하나를
전부 대조하려면 `pipeline/초역_상세/`에 보고서별로 **전문을 그대로 옮긴 원고**가
따로 있다 — 원문 전체, 한국어 전역, 판독 메모가 다 들어 있다.

로컬 다운로드 폴더에는 이 밖에도 NS 6/1, 4, 5, 6, 7, 8...이 추가로 받아져 있다
(invenio `digitalisat?id=` 직접 접근 방식으로 자동 다운로드 — 서버 429로 중단된 적
있음, 재개 시 항목 간 충분한 간격을 둘 것). 아직 이 저장소에 옮기지 않았다.

## 원본 접근 방법 (재현용)

1. invenio 검색 결과 페이지에서 항목의 "Digitalisat anzeigen" 링크 onclick 안의
   `id`(UUID, PrimeFaces 내부 id) 를 찾는다.
2. **그 링크를 실제로 한 번 클릭**해 서버 세션에 그 id를 "열람 승인"시킨다
   (팝업은 크롬 확장이 못 건드리는 별도 창이라 무시해도 된다).
3. 곧바로 `https://invenio.bundesarchiv.de/invenio/digitalisat?id={id}` 로
   직접 이동한다 — 이번엔 팝업이 아니라 일반 페이지라 자동화 가능.
4. 우측 상단 Download → "Gesamte AE (ZIP)" 선택된 채로 "Download starten".

**주의**: 서버가 짧은 시간에 여러 요청을 보내면 429(Too Many Requests)로 막는다.
항목 사이에 충분한 간격을 둘 것 — 공공기관 서버이니 예의를 지킨다.

## 저작권

Bundesarchiv는 FRUS(미국 정부 저작물)나 JACAR와 달리 **재사용에 대한 포괄적
허가를 주지 않는다** — "재사용자가 스스로 저작권법을 확인하라"는 입장이다.
다만 이 문서들은 1944년 작성된 **관공서의 익명 직무 저작물**(작성자 개인 서명
없음)이라, 독일 저작권법상 익명저작물 보호기간(발행 후 70년)이 이미 지났을
가능성이 높다 — 다만 이건 확정된 결론이 아니라 추정이며, 사이트에 실제로
게시하기 전에 재확인이 필요하다.
