# 문서철 열람기

자료를 가리지 않는 단일 HTML 열람기. **새 문서철은 데이터만 갈아끼우면 된다.**

```
열람기/
  build.py      ← 화면. 자료가 무엇인지 모른다
  SCHEMA.md     ← 데이터 규격
```

```bash
python3 ../열람기/build.py reading/collection.json
# → reading/reader.html
```

---

## 어떻게 갈아끼우나

열람기는 두 파일만 읽는다. **자료마다 다른 것은 전부 어댑터가 흡수한다.**

```
   자료 (문서철마다 제각각)
        │
        ▼
   make_docs.py          ← 문서철마다 하나. 여기만 새로 쓴다
        │
        ▼
   docs.json + collection.json   ← 규격 (SCHEMA.md)
        │
        ▼
   build.py              ← 공용. 고칠 일이 없어야 한다
        │
        ▼
   reader.html
```

새 문서철을 넣을 때 `build.py`를 건드리게 된다면 규격이 모자란 것이다.
그때는 규격을 넓히고 **기존 문서철도 함께 다시 만들어** 화면이 갈라지지 않게 한다.

두 자료는 생김새가 딴판인데도 같은 화면으로 나온다.

| | NDL | FRUS |
|---|---|---|
| 원본 | 스캔 `0324.jpg` (문자열 면 번호) | 지면 `1050.png` (숫자) |
| 영문 | OCR 교정본 | 정본 |
| 면 표시 | `[[page 0003]]` | `[1045면]` |
| 칩 | 주제 A~D | 문서 종류 |
| 정렬 | 편철순 | 문서번호순 |

어댑터가 이 차이를 전부 규격으로 옮긴다. 예를 들어 NDL의 `[[page 0003]]`은
어댑터에서 `[0003면]`으로 바뀐다.

## 없어도 되는 것

`collection.json`에서 빼면 그 기능이 화면에서 통째로 사라진다.
**스캔이 없는 자료도 그대로 쓸 수 있다.**

| 뺀 것 | 결과 |
|---|---|
| `pages` | 썸네일·확대 뷰어가 빠진다. 본문의 면 표시는 구분선으로만 남는다 |
| `groups` | 칩 줄이 사라진다 |
| `sorts` | 정렬 단추가 사라진다 |
| `panes.secondary` | 한국어/영문 전환이 사라지고 한 창만 나온다 |

## 화면

좌측은 목록(검색·칩·정렬), 우측은 본문. 두 창을 나란히 놓아 번역과 원문을 대조한다.
썸네일이나 본문 속 면 표시를 누르면 원본 지면이 열린다 (`←` `→` `Esc`).

겉모습은 처음 다룬 자료 — 극동군 G-3 전문철 — 의 어법을 물려받았다.
전신 용지의 등폭 서체, 기밀등급 도장의 자주색, 마이크로필름의 차가운 회청색.
장식이 아니라 자료가 원래 그렇게 생겼다.

**문서철이 바뀌어도 화면을 유지하는 건 읽는 사람이 자료를 옮겨 다닐 때마다
다시 적응하지 않게 하려는 것이다.** 그래서 새 자료에 맞춰 화면을 새로 만들지 않는다.

### 연대 바 — `chrono.json`

화면 아래에 떠 있는 띠다. 문서철을 가리지 않고 `열람기/chrono.json` 하나를 공용으로 쓴다.
문서를 하나씩 읽다 보면 「얄타가 언제였더라」를 매번 놓치기 때문에 둔 것이다.

- 문서를 고르면 **그 날짜가 창 한가운데로** 오도록 띠가 미끄러진다.
  휠·드래그로 직접 밀 수도 있고, 그때 표시는 제 날짜에 남는다.
- 사건 이름은 **위아래 층으로 흩어** 놓는다. 이름 너비를 재서 겹치지 않는 첫 층에
  얹는 방식이라, 1945년 8월처럼 열흘에 다섯 건이 몰려도 하나도 숨기지 않는다.
  층 수에 따라 바 높이가 알아서 정해진다.
- 해가 바뀌는 자리에 **선**을 긋고, 연도 이름표는 창 왼쪽에 들러붙는다.
  1945년 한복판을 보고 있어도 「1945」가 떠나지 않는다.
- 사건에 마우스를 올리면 **요약 카드**가 뜬다 (`hovercard.js` 재사용).
- **배율**은 하루 0.6px에서 32px까지 일곱 단계다 (`−` `+` 단추, `⌘/Ctrl`+휠).
  창 하나에 4년이 들어오는 눈에서 28일이 들어오는 눈까지. 배율을 바꾸면 층도
  다시 배정돼서, 벌릴수록 바가 낮아진다 (0.6px에서 9층 165px → 32px에서 2층 67px).
  줌은 창 안의 한 지점을 붙들고 그 둘레를 늘인다 — 보던 자리를 잃지 않는다.

```json
{"date": "1945-08-11", "label": "38선 획정", "key": true,
 "where": "장소 — 없어도 된다",
 "note": "마우스를 올렸을 때 뜨는 요약. 두세 문장을 넘기지 마라."}
```

`key: true`면 점이 커지고 자주색이 된다. `collection.json`에 `"chrono": false`를 두면
그 문서철에서는 띠가 통째로 빠진다.

## 만들어지는 파일

외부 의존이 없는 자체 완결형 HTML 한 장이다. 다만 `pages/`를 상대 경로로 참조하므로
**스캔을 쓰는 자료는 폴더째 옮겨야 한다.**

`file://`로 바로 열어도 되고, 문서철 폴더에서 `python3 -m http.server`로 띄워도 된다.
