## 왜 이 자료인가

기존에 가진 자료는 전부 **항복 이후**다.

```
FRUS 1945 v06        1945.02 ~ 09.26    ← 이 폴더. 결정이 내려지는 과정
014.1.korea.pdf      1945.09 ~ 1946.04  ← 하지 보고서 (APO 235)
NDL pid_9850431      1946.11 ~ 1948.04  ← 극동군 G-3 파일 091 File 1
```

NDL 「연합군 점령기 자료」(A00016)는 정의상 전후 자료군이라
`Cairo Declaration Korea`로 검색하면 0건이 나온다. 전시 결정 기록은 거기 없다.
NDL이 RG 353(SWNCC) `091 Korea (TS) 1945-1947`을 소장하긴 하지만
**마이크로피시**라 헌정자료실 현장 열람이다.

FRUS는 그 공백을 정확히 메운다. 그리고 스캔이 아니라 **이미 텍스트**라
OCR·판독교정 단계가 통째로 필요 없다.

## 파이프라인

NDL 자료(4단계)와 달리 여기는 **2단계**다. OCR과 문서분할이 필요 없다.

```
pipeline/frus_fetch.py        ① 수집 — history.state.gov → raw/dNNN.txt
pipeline/fix_footnotes.py     ①' 각주 번호 복원 (수집 뒤 한 번)
pipeline/frus_scans.py        ② 원본 지면 → pages/NNNN.png + raw/pages.json
pipeline/TRANSLATION_SPEC.md  ③ 번역 규칙 (서브에이전트가 읽는다)
pipeline/make_docs.py         ④ 자료 → reading/docs.json (열람기 규격)
../열람기/build.py            ⑤ 화면 — 공용. 이 문서철 전용이 아니다
```

```bash
cd pipeline
python3 frus_fetch.py frus1945v06 756 785 ../raw
python3 fix_footnotes.py ../raw
python3 frus_scans.py ../raw ../pages
# ③ 번역은 서브에이전트에 위임 — TRANSLATION_SPEC.md 를 프롬프트로 준다
python3 make_docs.py
python3 "../../열람기/build.py" ../reading/collection.json
open ../reading/reader.html
```

위 명령의 `../../열람기/`는 `pipeline/`에서 실행할 때의 경로다.
이 README 기준으로는 **`../열람기/`** — 문서철들과 나란히 있다.

**화면은 공용이다.** NDL 문서철과 같은 것을 쓴다.
자료마다 다른 것은 `make_docs.py` 하나가 흡수한다 — 규격은 `../열람기/SCHEMA.md`.

### 번역 방식

NDL 자료는 `pi` CLI로 DeepSeek에 넘겼지만, 이 묶음은 **서브에이전트에 위임**했다.
문서가 30건뿐이고 조각내지 않아도 되며, 외교문서 어법은 판단이 필요해서
스펙 문서 한 장을 주고 맡기는 편이 낫다.

배치는 글자 수 기준으로 나눈다 (문서 수가 아니라 — d781이 혼자 12,800자다).

### 열람기

NDL 「091 File 1 Korea」와 **같은 화면**이다. 두 자료를 오가며 읽을 텐데
화면이 서로 다르면 읽는 사람이 매번 다시 적응해야 한다.
썸네일과 확대 뷰어까지 같다.

자료가 달라서 다른 곳은 설정으로 흡수했다.

| | File 1 Korea | 여기 |
|---|---|---|
| 원본 | 스캔 `0324.jpg` | 지면 `1050.png` |
| 영문 | OCR 교정본 | **FRUS 정본** (교정 대상이 아님) |
| 좌측 칩 | 주제 A~D | **문서 종류** (각서·훈령 / 전보 / 서한 / 대화비망록 / 포고·보고) |

칩은 자료에 이미 있는 `doc_type` 값만 묶었다. 없는 분류를 지어내지 않았다.

### 원본 지면

FRUS 본문의 `[1019면]` 표시는 **면이 넘어가는 지점만** 찍혀 있어서 문서가 시작하는
면에는 표시가 없다. `frus_scans.py`가 첫 면 하나를 기준으로 이어 세어 복원한다 —
어떤 문서의 마지막 면이 다음 문서의 첫 면이다(한 면에 여러 문서가 실린다).

스캔 파일 이름은 인쇄 쪽번호가 아니라 물리적 장 번호다. **인쇄 쪽 + 12 = 파일 번호**
(앞머리 로마숫자만큼 어긋난다). 다른 권을 받을 때는 이 값을 다시 재야 한다.

`tr/*.json`에 영문을 중복 저장하지 않는다. 열람기가 `raw/`에서 직접 읽어 붙인다.

## ⚠️ 검증

한국어는 기계 번역이다. **인용 전에 반드시 원문과 대조할 것** —
열람기의 각 문서에 FRUS 원문 링크와 영문 접이식 원문을 달아 두었다.

조소앙의 로마자 표기가 문서마다 `Tjo`/`Tzo`로 갈리는 점도 같이 기록했다.
