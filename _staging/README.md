# 아직 옮기지 않은 것

원자료는 받아 뒀지만 번역이 안 끝난 것들이다. 화면에는 안 나온다
(`site.json` 의 문서철 목록에 없다).

| | 무엇 | 상태 |
|---|---|---|
| `FRUS_1945_EAC` | FRUS 1945 III 전권 · 유럽자문위원회 1,206건 | 색인만 만들어 둠. 이 중 133건을 날짜로 골라 `FRUS_1945_VEDay` 로 옮겼다 |
| `JPARMY_1945` | 『Reports of General MacArthur』 제2권 | XX 항복 결정 · XXI 평화로의 복귀 · 부록 천황과 전쟁 세 편(38만 자)을 잘라 뒀다 |

`JPARMY_1945` 는 **패전 뒤 옛 일본군 참모들이 GHQ의 지시로 쓴 자기 전쟁사**다.
부록은 기도 고이치 내대신의 비서관장이던 마쓰다이라 야스마사가 천황과 전쟁의
관계를 직접 쓴 글이다. 뒷날 『戦史叢書』의 바탕이 된 물건이다.
