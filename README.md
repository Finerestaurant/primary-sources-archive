# Primary Sources Archive

2차대전이 끝나가던 몇 달을, **그때 그 자리에서 쓰인 문서로** 읽는다.
번역과 원문과 원본 지면 스캔을 한 화면에 나란히 놓는다.

> **읽으러 가기 → https://finerestaurant.github.io/primary-sources-archive/**

역사책은 "5월 7일 독일이 랭스에서 항복했다"고 한 줄로 쓴다. 그 한 줄 뒤에는
새벽 2시 41분에 서명이 끝났는데 발표를 못 하게 막는 전보, 스탈린이 "동부전선이
그 명령을 따를 리 없다"며 다시 하자고 버티는 회담록, 스톡홀름 공사관이 새벽
2시에 히틀러가 죽었다더라고 보내는 전문이 있다. 그걸 그대로 놓아 둔 곳이다.

## 만드는 원칙

- **전문(全文)으로 옮긴다.** 발췌·요약하지 않는다.
- **당대의 표현을 그대로 둔다.** 지금 읽기 거북한 말도 고치지 않는다.
- **원문의 오타를 고치지 않는다.**
- **안 보이는 글자를 지어내지 않는다.** `□` 또는 `[원문 결락]`으로 남긴다.
- **스캔을 같이 올린다.** 번역을 의심할 수 있어야 한다.

한국어 번역은 기계 번역이다. 인용하기 전에 옆에 놓인 원문과 대조할 것.

## 문서철을 새로 넣을 때

**화면을 새로 만들지 않는다.** 어댑터 하나만 쓴다.

```
   자료 (문서철마다 제각각)
        ↓
   make_docs.py          ← 문서철마다 하나. 여기만 새로 쓴다
        ↓
   collection.json + docs.json
        ↓
   열람기/build.py       ← 공용
        ↓
   reader.html
```

규격은 `열람기/SCHEMA.md`. `build.py`를 고쳐야 하는 상황이 오면 그건 규격이
모자란 것이다 — 규격을 넓히고 **기존 문서철도 함께 다시 만들어** 화면이
갈라지지 않게 한다. 읽는 사람이 자료를 옮겨 다닐 때마다 화면에 다시 적응하지
않게 하려는 것이다.

아직 안 옮긴 자료는 `_staging/`에 있다.
