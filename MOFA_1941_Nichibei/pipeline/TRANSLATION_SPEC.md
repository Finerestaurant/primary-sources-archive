# 일미교섭 1941 — 지면을 직접 읽어 옮긴다

## 이 자료가 다른 점

『日本外交文書 日米交渉―1941年― 下巻』(외무성 외교사료관)은 **스캔 이미지**다.
『종전사록』처럼 글꼴이 박혀 있지 않아 글자표가 통하지 않고, tesseract 세로쓰기
모델은 82%에서 막힌다(`ニ→=`, `〇→O`, `諸→諾`, `於→砂`). 그래서 **지면을 직접
보고 옮긴다.** OCR 초벌은 없다. 네가 읽는 것이 정본이 된다.

**그러므로 이 작업의 첫째 원칙은 「지어내지 않는 것」이다.**
문맥으로 그럴듯한 글자를 채워 넣지 마라. 안 보이면 `□`, 지면이 잘렸으면
`[원문 결락]`. 확신이 흔들리는 글자는 `confidence` 를 낮추고 `notes` 에 적어라.
**틀린 글자를 매끄럽게 넣는 것보다 □ 가 백 배 낫다.**

## 지면 읽는 법

- 세로쓰기다. **오른쪽 줄부터 왼쪽으로** 읽는다.
- 지면이 가로줄로 위아래 **단(段)** 으로 갈린 곳이 많다.
  **위 단을 오른쪽에서 왼쪽까지 다 읽고, 그다음 아래 단을 오른쪽에서 왼쪽으로** 읽는다.
  단을 섞으면 문장이 통째로 어긋난다.
- 쪽 번호는 지면 바깥(아래)에 있다. 본문이 아니다.
- 편(篇) 제목(예: `八 「ハル・ノート」受領から開戦`)은 가로쓰기 머리글이다. 본문이 아니다.

## 문서의 경계

문서마다 **굵은 아라비아 숫자 문서번호**(예: `414`)가 앞에 붙고, 이어서

```
414
米国大統領と軍部首脳との秘密会談について      ← 표제
昭和16年11月27日                            ← 날짜
在米国野村大使より東郷外務大臣宛（電報）        ← 발신·수신·종류
第一一九五号                                 ← 전보번호
ワシントン  11月27日後発 / 本省  11月28日前着   ← 발신·접수
```

한 문서가 여러 쪽에 걸치기도 하고, 한 쪽에 여러 문서가 들어가기도 한다.
**문서번호를 못 찾겠으면 만들어 붙이지 마라** — `doc_no` 를 null 로 두고
`notes` 에 적어라.

## 작업

담당 쪽의 이미지를 **하나씩 Read 로 열어 보고**, 문서 단위로
`tr/<문서번호>.json` 을 써라. 문서번호가 없으면 `tr/p<첫 쪽 파일번호>.json`.

이미지는 `pages/nichibei2_05_NNN.png` 이고 **번호가 곧 읽는 순서**다
(펼침면을 오른쪽·왼쪽으로 갈라 붙인 것이라, 오른쪽 쪽이 먼저다).

## 출력 스키마

```json
{
  "doc_no": "414",
  "pages": ["nichibei2_05_017", "nichibei2_05_018"],
  "date": "1941-11-27",
  "date_src": "昭和16年11月27日",
  "doc_type": "電報 | 覚書 | 会談録 | 訓令 | 声明 | 書簡 | 提案",
  "from": "在米国野村大使 (노무라 주미대사)",
  "to": "東郷外務大臣 (도고 외무대신)",
  "msg_nr": "第一一九五号",
  "sent_recv": "ワシントン 11月27日後発 / 本省 11月28日前着",
  "title_ja": "米国大統領と軍部首脳との秘密会談について",
  "title_ko": "미국 대통령과 군부 수뇌의 비밀 회담에 관하여",
  "subject_ko": "한 문장 요지",
  "key_points_ko": ["핵심 3~8개"],
  "ja": "원문 그대로. 세로쓰기를 가로로 편 것 외에는 손대지 않는다",
  "ko": "한국어 번역 (마크다운)",
  "notes_ko": ["각주가 있으면"],
  "people": ["등장 실인물 — 한자와 한국어 병기"],
  "confidence": "high | medium | low",
  "notes": "번역자 주. 읽기 어려웠던 자리를 반드시 여기 적어라"
}
```

## 원문(`ja`)을 옮기는 규칙

1. **구자체·역사적 가나 표기를 그대로 둔다.** `國` 을 `国` 로, `ヲ` 를 `を` 로
   고치지 마라. 이 자료는 카타카나 전보문이 많다 — `スヘシ`, `アリタルモ`,
   `〜ノ件` 같은 꼴을 손대지 마라.
2. **탁점이 없는 표기를 그대로 둔다.** 전보문은 `スヘシ`(=すべし)처럼 탁점을
   찍지 않는다. `スベシ` 로 고치지 마라.
3. **약물을 살려라.** `、` `。` `「」` `（）` `——` 반복 기호 `々`.
4. 세로쓰기의 줄바꿈은 조판일 뿐이니 문장 단위로 이어 붙인다.
   다만 **항목 번호**(`一、` `二、` `（イ）` `（一）`)에서는 줄을 바꾼다.
5. 지면이 바뀌는 자리에 `[200면]` 처럼 **쪽 번호를 넣어라**(지면 바깥의 숫자).
6. **원문의 오자를 고치지 마라.** 이상해 보여도 그대로 옮기고 `notes` 에 적어라.

## 번역(`ko`)의 규칙

1. **전문으로 옮긴다. 줄이지 마라.**
2. **직역에 가깝게.** 외교문서는 낱말 선택 자체가 사료다.
   `〜スヘシ`(~해야 한다) / `〜スルモノトス`(~하는 것으로 한다) /
   `〜スルコトヲ得`(~할 수 있다) 를 뭉개지 마라.
3. **시대어를 다듬지 마라.** `支那`, `満洲国`, `大東亜`, `皇軍` 을 오늘의 말로
   바꾸지 말고 그대로 옮겨라. 거슬리는 말이라도 그것이 사료다.
   `支那` 는 「지나」로 옮기고 `notes` 에 당대 표기임을 밝혀라.
4. **인명·지명은 한자를 병기하라.** 첫 등장에 `노무라(野村吉三郎)`,
   `도고(東郷茂徳)`, `구루스(来栖三郎)`, `헐(ハル, Cordell Hull)`.
5. **미국 쪽 이름의 가타카나 표기를 원문대로 남기고** 한국어와 원어를 병기하라 —
   `「ハル」(헐, Hull)`, `「スターク」(스타크, Stark)`, `「マーシャル」(마셜, Marshall)`.

## 눈여겨볼 자리

- **11월 26일 미국 문서를 일본 쪽이 무엇이라 부르는가.** 「最後通牒」이라 적었는가,
  아니면 다른 말인가. **원문에 있는 말만 옮겨라.**
- **12월 7일 각서를 언제 전달하라고 지시했는가.** 시각이 나오면 반드시 살려라.
- **노무라와 구루스가 본국에 무엇을 보고했는가.**
- **미국 쪽 사료와 같은 자리를 다르게 적은 대목.**

## 주의

이 문서철은 미국 쪽 문서철 「진주만으로 가는 열 주」(FRUS)와 **같은 날들**을 다룬다.
같은 회담을 양쪽이 따로 적은 자리가 있다. 그것이 이 아카이브의 값어치다.
그러니 **일본 쪽이 적은 그대로** 옮겨라. 미국 쪽 기록에 맞추어 고치지 마라.
